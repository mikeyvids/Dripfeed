🎮 Dripfeed Scheduler

Turn a big game library into a paced release calendar. Choose games already on your card, choose when they appear, and optionally add a short occasion message.

Your library stays local: Dripfeed manages the waiting queue on your card. MiSTer reveals each game when its day arrives.

This tool needs Chrome, Edge, Brave, or another Chromium browser.
Safari and Firefox can't write to your SD card from a web page yet. Please re-open this file in Chrome or Edge.
1 Connect your SD card

Insert the MiSTer SD card, then choose the whole card so scheduling, messages, and menu settings stay together. You can also choose only the games folder for basic scheduling.

Not connected

Choose the folder itself and click Open / Select. Individual files look greyed out because the browser is asking for a folder; your game list appears here after connecting.

Advanced: folder names & staging

Scheduled games wait outside games/, grouped by system (for example .dripfeed-library/SNES/). That keeps held-back titles out of ordinary game-library scans. Existing games/SYSTEM/.dripfeed/ queues are still read safely after an upgrade.

Use either, both, or neither — scheduling and reveals work regardless; these only control the menu folders Dripfeed builds.

Names are cleaned automatically: emojis and characters MiSTer can't show are removed, a leading _ is added if missing (folders need it to appear in the menu; _@ pins to the top). With the date toggle ON the Dripfeed folder is named for the latest Dripfeed (e.g. _Dripfeed - New Fri Jul 3, 26) — it only ever renames when a game actually unlocks, never on a plain power-on, and never sits empty-dated. Toggle OFF for a fixed name. The MiSTer menu shows ~30 characters, so the length limits below adjust to leave room for whatever the toggles add.

2 Choose games

Switch systems freely — your picks stay in one selection, so you can batch games from several cores together and give them all the same date.
Note: unlocks happen on the console, and only once it has a trusted clock (network time or RTC) after power-on — so a game appears the first time the console is on during/after its date.

0 selected

For a “hide nearly everything” setup: select all systems, untick the few games you want visible, then schedule the remaining selection. Already unveiled games stay protected unless you turn on the override.

3 Choose the day & (optional) message

When the games unlock that day, this renames the "What's New" menu folder (e.g. _Dripfeed - Happy Birthday Deme, trimmed to fit the screen) and it stays until the next unlock — powering the console on never renames it. Also shows in full on the on-screen banner and in gamelist.xml for graphical frontends.

⇪ Bulk import from CSV

Columns: path, date, message — where path is relative to your games folder (e.g. MegaDrive/Shiny Forts.md), date is the unlock date (YYYY-MM-DD or M/D/YYYY), and message is an optional banner. A header row is recognized automatically. You can also drop a whole multi-disc folder path (e.g. Saturn/Shiny Forts III). GOT'eM rows ride the same file: put a month in the date column (2026-08 or 8/2026) and the row becomes that month's Game of the Month pick (message column = optional shortcut label; _Arcade/…mra allowed). Any columns after the first three are reference-only and ignored — keep genre, console, players, hours_to_beat, series, release_date (or anything else) in your master spreadsheet and import the same file as-is.

🏆 GOT'eM — the Game of the Month scheduler

Creates a _Game of the Month folder in the MiSTer menu with a shortcut to your pick — consoles, handhelds, computers, and arcade (.mra) all work. The game itself is never renamed or moved: visible games stay visible, and a pick that's still scheduled/hidden appears automatically the day Dripfeed reveals it. One pick per month; the folder rebuilds when the month rolls over.
