Add a Wi‑Fi profile

The password is converted to a WPA key in this browser, then written only to the selected SD card. It is never uploaded or placed in this HTML file.

Country matters: use the country where the MiSTer is operating so its Wi‑Fi radio follows local channel rules. Wifi‑Swap supports WPA/WPA2 Personal and open networks—not business/enterprise login pages or captive portals.

Then, on MiSTer

  1. Safely eject the SD card and return it to MiSTer.
  2. Open Scripts → wifi-swap.sh. It uses a compatible official Wi‑Fi helper already on the card; if needed, it can cache the current helper when MiSTer has internet.
  3. Choose a network profile. Switching can end an active SSH, CIFS, or browser connection.

Seeing the same Wi‑Fi name more than once in a network scan? One router can advertise separate 2.4, 5, or 6 GHz access points. The Registry still saves one friendly profile, and Wifi‑Swap selects that exact profile internally.

Wifi‑Swap preserves networks owned by the official Wi‑Fi tool. Its own blocks are clearly marked in linux/wpa_supplicant.conf and are installed transactionally when you run the MiSTer script.
