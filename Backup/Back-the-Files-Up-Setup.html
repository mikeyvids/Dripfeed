Exactly what is protected

This boundary is built into the script. A typo in setup cannot quietly turn it into a giant everything-backup.

✓ Included

  • Current player's complete profile: saves, save states, achievements settings, wallpapers, and menu image
  • Every stored profile: everything inside profiles/, including archived profiles
  • Dripfeed: schedule, configuration, reveal history, and recovery state
  • MiSTer settings: the small settings in config/ and MiSTer.ini

× Not included

  • ROMs or disc images
  • Rebuildable databases, caches, thumbnails, or logs inside config/
  • Unrelated media or screenshots
  • Other files outside the fixed list
  • This cloud authorization in its own backup

The RetroAchievements file may contain a token. Treat every local or cloud archive like a password.

Restore is built in: On MiSTer, open Scripts → backtheFup.sh → Restore from a local backup. Pick everything, every player, one player, or just one part such as saves. The script checks the backup and makes a Before Restore safety copy first.

Where should verified backups go?

Copy the finished authorization

Run rclone config file, open that file, and paste all of it below—or choose the file. It contains a reusable refresh token, not your Google password. You normally authorize once; repeat only if access is revoked, expires, or you deliberately replace it.

Then, on MiSTer

One menu item does the job

  1. Safely eject the SD card and return it to MiSTer.
  2. Make sure MiSTer has a believable date and time before cloud use.
  3. Open Scripts → backtheFup.sh.
  4. Choose Check cloud connection once, then Back up everything now.
  5. To recover data later, choose Restore from a local backup and follow the controller prompts.

Each run creates and verifies local archives first. Cloud failure never deletes that local copy. Google normally does not ask you to sign in for every backup; rclone renews short-lived access with the saved refresh token.
